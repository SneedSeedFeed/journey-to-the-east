# Journey to the East
A small submod for Princes of Darkness:
- Immortal Qiao users get an alternative way to avoid the penalties of the higher perks.
- Western hunters can learn Qiao, sort of like how western vampires can learn Hun and Po. Don't take this one too seriously because I didn't.
- Hun and P'o vampires can "two Saulots" themselves, separating out their Hun and P'o, creating a nemesis that will hopefully come back to bite them and be a thorn in their side.
